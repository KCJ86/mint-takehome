    - Synchronisation menu et inventaire en temps réel
    - Support de structures de menu complexes (modificateurs, combos)
    - Groupes de restaurants multi-emplacements
    - Intégration main-d'œuvre
    - Synchronisation cartes cadeaux et fidélité

```javascript
// Configuration via SDK
const salsa = new SalsaClient(apiKey);

await salsa.integrations.connect({
  provider: "toast",
  credentials: {
    clientId: process.env.TOAST_CLIENT_ID,
    clientSecret: process.env.TOAST_CLIENT_SECRET,
    restaurantGuid: process.env.TOAST_RESTAURANT_GUID,
  },
  options: {
    syncInterval: "5m",
    includeLabor: true,
    menuMapping: "auto",
  },
});
```

## Chaîne d'approvisionnement et distributeurs

Automatisez la commande d'ingrédients avec intégrations directes de distributeurs :

<Tabs>
  <Tab title="Sysco">
    <Badge color="green" shape="rounded" size="md">⭐⭐⭐⭐⭐ Native</Badge>

    **Fonctionnalités :**
    - Commande automatisée basée sur prévisions IA
    - Disponibilité d'inventaire en temps réel
    - Mises à jour de tarifs et catalogue
    - Suivi de commande et notifications de livraison
    - Réconciliation des factures

    **Avantages :**
    - Réduction de 40% du temps de commande
    - Quantités optimales basées sur prévisions
    - Comparaison automatique des prix
    - Réduction de 60% des ruptures de stock

```python
    # Exemple : Commande Sysco automatisée
    from salsa_sdk import SalsaClient

    client = SalsaClient(api_key="votre_cle")

    sysco_config = client.suppliers.configure("sysco", {
        "account_number": "123456789",
        "delivery_window": "mar-jeu",
        "auto_order": True,
        "approval_threshold": 500,
        "preferred_items": True
    })
```

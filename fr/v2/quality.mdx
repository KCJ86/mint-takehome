## Aperçu

La v2.0 introduit la prédiction de qualité IA, l'équipement de test IoT automatisé et la vision par ordinateur pour l'inspection visuelle. Détectez les problèmes de qualité avant qu'ils ne se produisent.

---

## Prédiction de qualité IA

### Notation de qualité prédictive

L'IA prédit les scores de qualité avant la fin du lot :

<CardGroup cols={2}>
  <Card title="Analyse des ingrédients" icon="flask">
    Analyse les données de qualité des ingrédients et surveille les conditions de production en temps réel pour prédire les scores finaux avec une précision de 95%.
  </Card>
  <Card title="Système d'avertissement précoce" icon="bell">
    Fournit des avertissements précoces pour les problèmes potentiels avant qu'ils n'impactent votre lot, vous donnant le temps d'intervenir.
  </Card>
</CardGroup>
```javascript
// Exemple : Obtenir la prédiction de qualité IA
const prediction = await salsa.ai.quality.predict({
  batch_id: "BATCH-2024-001",
  current_stage: "mixing"
});
console.log(`Qualité prévue : ${prediction.score}/10`);
console.log(`Confiance : ${prediction.confidence}%`);
```

## Notation de qualité

### Notation améliorée par IA

L'apprentissage automatique améliore l'évaluation de la qualité en combinant les scores automatisés des capteurs avec les saisies manuelles :

```javascript
// Exemple : Enregistrer la qualité avec assistance IA
const qualityCheck = await salsa.ai.quality.recordScore({
  batch_id: "BATCH-2024-001",
  automated_scores: {
    visual_ai: 9.2,
    ph_sensor: 8.8,
    viscosity: 9.0,
    temperature: 10.0,
  },
  manual_scores: {
    taste: 9.5,
  },
  ai_analysis: true,
});
```

## Démarrage

<Steps>
  <Step title="Installer l'équipement IoT">
    Configurez les capteurs automatisés et les caméras de vision par ordinateur dans vos zones de production.
  </Step>
  <Step title="Former le système IA">
    Laissez l'IA apprendre de vos normes de qualité pendant 2-4 semaines avec vos données historiques.
  </Step>
  <Step title="Activer les tests automatisés">
    Activez les tests de qualité automatisés complets dans **Contrôle qualité > Fonctionnalités IA**.
  </Step>
  <Step title="Configurer les seuils">
    Définissez vos scores de qualité minimaux dans **Contrôle qualité > Normes**. L'IA les ajustera automatiquement avec le temps.
  </Step>
  <Step title="Examiner les insights IA">
    Examinez régulièrement les prédictions et recommandations IA pour améliorer continuellement votre production.
  </Step>
</Steps>

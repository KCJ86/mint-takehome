## Guide de dépannage - v2.0

Ce guide vous aide à résoudre les problèmes courants avec Salsa as a Service v2.0, y compris les prévisions IA et les problèmes de capteurs IoT. Si vous ne trouvez pas de solution ici, notre équipe de support est prête à vous aider.

---

## Diagnostics rapides

Avant de plonger dans des problèmes spécifiques, effectuez ces vérifications rapides :

<Steps>
  <Step title="Vérifier l'état du système">
    Visitez notre [page de statut](https://status.salsaasaservice.com) pour voir
    s'il y a des problèmes de service en cours.
  </Step>
  <Step title="Vérifier la connexion Internet">
    Assurez une connexion Internet stable. v2.0 fonctionne hors ligne mais
    nécessite une connexion périodique.
  </Step>
  <Step title="Vider le cache">
    Videz le cache du navigateur ou les données de l'application mobile, puis
    essayez de vous reconnecter.
  </Step>
  <Step title="Vérifier les capteurs IoT">
    Si vous utilisez des capteurs, vérifiez qu'ils sont en ligne et connectés.
  </Step>
</Steps>

## Problèmes de prévisions IA

### Prévisions inexactes

**Problème** : Les prévisions IA ne semblent pas précises

<Steps>
  <Step title="Vérifier les données historiques">
    Assurez-vous d'avoir au moins 90 jours de données historiques importées.
  </Step>
  <Step title="Vérifier les sources de données">
    Confirmez que toutes les sources de données (POS, réservations, etc.) sont
    connectées.
  </Step>
  <Step title="Période d'apprentissage">
    L'IA nécessite 2-4 semaines pour s'entraîner. La précision s'améliore avec
    le temps.
  </Step>
  <Step title="Contacter le support IA">
    Pour des problèmes persistants, contactez notre équipe IA :
    ai-support@salsaasaservice.com
  </Step>
</Steps>

## Problèmes de capteurs IoT

### Capteur hors ligne

**Problème** : Le capteur IoT n'envoie pas de données

<Tabs>
  <Tab title="Vérifications de base">
    <Steps>
      <Step title="Vérifier la batterie">
        Vérifiez la batterie du capteur et remplacez-la si nécessaire.
      </Step>
      <Step title="Vérifier la portée réseau">
        Assurez-vous que le capteur est à portée du réseau WiFi/Bluetooth.
      </Step>
      <Step title="Redémarrer le capteur">
        Redémarrez le capteur et vérifiez l'état du réseau.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Reconnexion">
    <Steps>
      <Step title="Ouvrir l'application mobile">
        Ouvrez l'application et allez dans **Paramètres > Capteurs IoT**.
      </Step>
      <Step title="Trouver le capteur hors ligne">
        Localisez le capteur hors ligne dans la liste.
      </Step>
      <Step title="Reconnecter">
        Appuyez sur "Reconnecter" et suivez les instructions de couplage.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Recalibration">
    <Steps>
      <Step title="Accéder aux paramètres">
        Accédez aux paramètres du capteur dans l'application.
      </Step>
      <Step title="Lancer la calibration">
        Sélectionnez "Recalibrer" et suivez la procédure guidée.
      </Step>
      <Step title="Tester la lecture">
        Testez avec une lecture de référence pour confirmer la précision.
      </Step>
    </Steps>
  </Tab>
</Tabs>

### Lectures de capteur erronées

**Problème** : Le capteur envoie des données mais elles semblent incorrectes

- **Recalibrer le capteur** : Exécutez une routine de calibration
- **Vérifier le placement** : Assurez-vous que le capteur est correctement positionné
- **Vérifier les interférences** : Éloignez des sources de chaleur ou d'humidité
- **Remplacer la batterie** : Une batterie faible peut causer des lectures inexactes

## Synchronisation des données

### Problèmes d'intégration POS

**Problème** : Les données POS ne se synchronisent pas avec v2.0

<Tabs>
  <Tab title="Square">
    <Steps>
      <Step title="Déconnecter l'ancienne intégration">
        v2.0 utilise l'API Square v2. Déconnectez l'ancienne intégration v1.0.
      </Step>
      <Step title="Reconnecter avec v2.0">
        Reconnectez avec la nouvelle intégration v2.0.
      </Step>
      <Step title="Autoriser les nouvelles permissions">
        Autorisez toutes les nouvelles permissions requises par v2.0.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Toast">
    <Steps>
      <Step title="Vérifier la version API">
        Confirmez que vous utilisez Toast API v2.
      </Step>
      <Step title="Mettre à jour les identifiants">
        Mettez à jour vos identifiants API dans **Paramètres > Intégrations**.
      </Step>
      <Step title="Tester la connexion">
        Retestez la connexion et vérifiez les journaux de synchronisation.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Synchronisation en temps réel">
    <Steps>
      <Step title="Vérifier les webhooks">
        Confirmez que les webhooks sont configurés correctement.
      </Step>
      <Step title="Tester la livraison">
        Testez la livraison des webhooks dans **Paramètres > Développeur**.
      </Step>
      <Step title="Vérifier les journaux">
        Examinez les journaux de synchronisation pour identifier les erreurs.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## API GraphQL

### Erreurs de requête GraphQL

**Problème** : Les requêtes GraphQL échouent ou retournent des erreurs

```graphql
# Vérifiez le schéma GraphQL
query IntrospectionQuery {
  __schema {
    types {
      name
    }
  }
}

# Utilisez l'explorateur GraphQL interactif
# https://api.salsaasaservice.com/graphql
```

**Erreurs courantes :**

- **Erreur d'authentification** : Vérifiez le token Bearer dans les headers
- **Champs invalides** : Utilisez l'introspection pour vérifier les champs disponibles
- **Limite de profondeur** : Les requêtes sont limitées à 10 niveaux de profondeur
- **Limite de taux** : Respectez les limites de taux GraphQL

## Performance

### Chargement lent du tableau de bord

**Problème** : Le tableau de bord v2.0 charge lentement

<Steps>
  <Step title="Vérifier la connexion">
    v2.0 nécessite une connexion stable. Testez votre vitesse Internet.
  </Step>
  <Step title="Réduire les widgets">
    Si vous avez beaucoup de widgets sur le tableau de bord, envisagez d'en
    désactiver certains.
  </Step>
  <Step title="Vider le cache">
    Videz le cache du navigateur pour forcer un rechargement complet.
  </Step>
  <Step title="Synchronisation hors ligne">
    Si hors ligne, attendez que l'application synchronise avec le serveur.
  </Step>
</Steps>

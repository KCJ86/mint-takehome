### 📚 Migration depuis v1.0

<Tabs>
  <Tab title="Migration automatique">
    **Recommandé pour la plupart des clients**
    <Steps>
      <Step title="Demander la migration">
        Demandez la migration depuis votre tableau de bord via notre outil
        automatisé.
      </Step>
      <Step title="Validation des données">
        Notre système valide et vérifie toutes vos données avant la migration.
      </Step>
      <Step title="Exécution parallèle">
        Exécutez v1 et v2 simultanément pendant la période de transition.
      </Step>
      <Step title="Transfert des données">
        Toutes les données, recettes et intégrations sont transférées sans temps
        d'arrêt.
      </Step>
      <Step title="Formation">
        Recevez des sessions de formation gratuites sur les nouvelles
        fonctionnalités v2.0.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Migration manuelle">
    **Pour les clients avec configurations personnalisées complexes**
    <Steps>
      <Step title="Exporter les données">
        Exportez toutes les données de v1.0 avec notre outil de migration.
      </Step>
      <Step title="Révision de compatibilité">
        Examinez le rapport de compatibilité pour vos configurations
        personnalisées.
      </Step>
      <Step title="Ajuster les intégrations">
        Mettez à jour les intégrations personnalisées pour les nouveaux
        endpoints API v2.0.
      </Step>
      <Step title="Importer les données">
        Importez les données validées dans votre nouveau compte v2.0.
      </Step>
      <Step title="Valider">
        Validez et testez tout avant de basculer complètement.
      </Step>
    </Steps>
  </Tab>
